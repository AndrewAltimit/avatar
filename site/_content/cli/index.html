CLI commands

Everything is driven through the single avatar binary (crate avatar-cli, clap v4 subcommands). The groups below mirror the layers: FBX/armature on the 3D side, lint/stats on the project side, anim-gen for generation, and osc for the live runtime. Run any command with --help for flags.

FBX & armature

CommandWhat it does
avatar fbx inspect <model.fbx>Node hierarchy, skeleton roots, bone count, scale/orientation, units; flags unapplied transforms, wrong axis/units, extra root, unskinned mesh, missing T-pose.
avatar armature check <model.fbx>Map detected bones → Unity Humanoid; report missing/mis-mapped. Exits 0 when humanoid-ready.
avatar armature fix <model.fbx>Print the repair plan (dry run by default).
avatar armature fix <model.fbx> -o fixed.fbxWrite a repaired FBX: canonical bone renames applied; topology/scale/orientation flagged, not applied.

Details: docs/reference/armature-repair.md.

Lint & stats

CommandWhat it does
avatar lint <UnityProject>SDK3 compliance report; exits non-zero on errors.
avatar lint <UnityProject> --deny-warningsAlso fail on warnings — gate CI directly.
avatar stats <model.fbx>Performance rank from geometry (triangles/meshes/material slots/bones).
avatar stats <UnityProject>Performance rank from per-avatar components (PhysBones/colliders/contacts/particles/constraints, texture VRAM for PC + Android).

Rule codes: docs/reference/sdk3-lint-rules.md. Metrics: docs/reference/performance-stats.md.

Asset generation

CommandWhat it does
avatar anim-gen clip --name Smile --blendshape Body:Smile:100 -o Smile.animEmit a Unity .anim clip (blendshape-weight / GameObject-active curves).
avatar anim-gen blendtree ...Emit an FX-layer analog-gesture blend tree (BlendTree, blending GestureLeft/RightWeight).

Output goes to stdout or -o, with deterministic fileIDs so assets are diffable. Details: docs/reference/anim-gen.md.

OSC runtime

CommandWhat it does
avatar osc send <param> <value>Set an avatar parameter on a running VRChat (e.g. osc send VRCEmote 3).
avatar osc input ...Drive /input/* axes & buttons (with reset-to-zero).
avatar osc monitorPoll inbound OSC on :9001.
avatar osc changeHandle /avatar/change.
avatar osc query <config.json>Parse an avatar's OSCQuery config offline: parameter names, OSC type tags, read/write access.
avatar osc gestures --seconds 10Run the analog-gesture daemon (headless demo sweep; --hz/--period tunable).

Details: docs/reference/osc-runtime.md.
