FBX analyzer

Drop an avatar .fbx and get the same diagnosis the CLI gives — humanoid rig check, VRChat performance rank, blendshape inventory — right here in the browser. The analysis is the actual Rust diagnose graph (avatar-fbx + avatar-armature + avatar-stats) compiled to WebAssembly, so it matches avatar describe output bit for bit.

Your file never leaves this page. There is no upload: the file is read into memory, analyzed by WebAssembly locally, and forgotten on reload. Nothing is sent to any server — this site is static hosting.

What it checks

  • Humanoid rig — infers the Unity humanoid mapping from the bone hierarchy and validates it against VRChat's rig requirements: required + recommended bones, duplicate mappings, stray skeleton roots. See humanoid bones and armature repair for what the CLI can then fix.
  • Performance rank — VRChat's Excellent→Very Poor rank computed offline from the geometry (triangles, meshes, bones, materials), against both the PC and Android limit tables. See performance stats.
  • Blendshapes — every blendshape channel and the mesh it deforms; the raw material for visemes and expressions.

Only binary FBX 7.x is supported (the Autodesk / Unity / Blender default export) — ASCII FBX must be re-exported as binary. Project-level checks (descriptor, animators, menus, the SDK3 lint rules) need a full Unity project tree, so those stay on the CLI: avatar lint.
